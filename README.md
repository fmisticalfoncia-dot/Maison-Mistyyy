# Maison Mistyy

A house of evening wear. Champagne Muse is the opening campaign.

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS v4 · shadcn/ui structure · GSAP

```bash
npm install
npm run dev
```

## Site

- `/` — campaign, lookbook, atelier, private client
- `/privacy` · `/terms`

Components live in `components/ui` (Endless corridor, cinematic footer).
